# Blender ship & crew assets (GLB contract)

Ships are procedural (`src/ships`) **except** the ones that have a GLB in `public/models/ships/<id>.glb`.
`createShip(spec)` uses the GLB when it was preloaded (`loadShipAssets()` in `main.ts`) and falls back to the procedural
ship otherwise, so a missing or broken file never stops the game. All 16 ships have a GLB, all from the one generic builder
(`tools/blender/make_ships.py` + `shipbuilder.py`, a Python port of `src/ships` driven by `tools/blender/ships.json`; the local Llama
runs it, see `BLENDER_PIPELINE.md`). `tests/assets.test.ts` enforces this contract for every ship.

## Ship GLB
Space: glTF Y-up export of Blender Z-up, +x bow, +y up, +z starboard, metres, waterline y = 0 (Blender +Y is port; glTF z = −Blender y).

| Node | Rule |
|---|---|
| `<id>` | root empty |
| `LOD0`, `LOD1`, `LOD2` | one child group per level; the game only toggles `.visible` (LOD0 is the hero model) |
| `LODn_Body` | static hull, deck, mast, rigging, jib … merged by material |
| `LODn_trim-aft` | (legacy hand-made tartane only; no shipped ship uses it any more, the game still accepts it) **sail pivot on the mast axis at deck height** (translation = `meta.trimPivot`). The game rotates it about Y and scales Y/Z for wind and sail level. Square rigs use `LODn_trim-square`. `setSailTrim` matches on `endsWith('trim-aft' / 'trim-square')` |
| `LODn_AftSail` | yard + sail, pivot-local, child of the pivot |
| `LODn_m<i>_trim-square` / `_trim-aft` | the generic builder (every ship): one pivot per sail group of mast `i` (square sails, and the spanker/gaff/lug/lateen sail), sails named `LODn_m<i>_SquareSail` / `_AftSail` |
| `LOD0_Glass` | generic builder: emissive stern windows and lanterns (LOD0 only) |
| `LOD0_LanternGlass` | the only emissive material (LOD0 only) |

- **Names:** letters, digits, `_` and `-` only. `GLTFLoader` strips dots, and Blender adds `.001` to duplicates, so a clash silently renames a node.
- **Budgets (every ship)** scale with length `L`: LOD0 ≤ 1700 + 140 L, LOD1 ≤ 160 + 20 L, LOD2 ≤ 60 + 6 L (written to `meta.budgets` and re-checked by the tests); LOD1 < 30 % and LOD2 < 60 % of the level above. Measured: tartane 2,199 / 384 / 86, yacht 2,655 / 392 / 94 … battleship 6,455 / 718 / 290; LOD0 is 2–6 draw calls (body, one per sail pivot, glass).
- **Full-quality extras (LOD0 only, generic ships):** cannon muzzles in the ports, rudder, an anchor on each bow, ratlines between the shrouds, a hatch coaming in the waist and up to three cargo barrels (both deck obstacles in `meta.json`), deck plank seams, hull plank lines, rivets on the wale, a stern lantern post (ships without a sterncastle) and smooth-shaded sails.
- **Materials:** at most 3 for the whole file: one `*_atlas_mat` (4×4 flat colour swatches, 256 px, every face maps to one swatch centre), the emissive glass and `*_flag` (pennants and the stern ensign, node `LODn_Flag`; the game clones it per ship and sets the nation colour). Colours stay editable in `<id>_atlas.png`; faces never need unique UVs.
- **LODs are regenerated by rule, not decimated** (`tools/blender/shipbuilder.py` `LOD_CFG`): fewer hull stations/ring points, no seams/rivets/props, a coarser sail grid, 4/6-sided spars. The wale (cream band) is baked into the hull swatches at LOD1/2 so the colour does not pop when the level changes.
- **Bounds:** length (stern to bowsprit tip) at least `spec.length`; every ship ≤ 1.15 × + bowsprit + 1 m; beam within −10 %/+15 % of `spec.beam` plus 1.2 m for muzzles and anchors (and up to 0.4 L for oared ships); keel below the waterline.
- **Spec link:** generated ships carry `meta.specHash` (FNV-1a of the canonical spec JSON); the tests recompute it from `specs.ts`, so changing a spec fails them until the ship is regenerated. Sail pivots must sit on their mast base (`(0.5 − at)·L`) on every LOD.
- **Size:** every ship < 500 KB (largest today: battleship 452 KB, embedded atlas included). No meshopt/KTX2 until the asset set exceeds a few MB.

## `<id>.meta.json` (written by the generator, read by `ships/deck.ts`)
`lods` (tris/meshes/drawCalls, must equal the GLB), `trimPivot`, `lantern`, `deck.stations` (`[x, y, halfWidth]` per hull station: deck height and **walkable** half width, already inset from the rail and 0 where the bow is too narrow) and `obstacles` (circles/rects in ship-local x/z: mast, hatch, barrels, anchor, tiller, lantern pole). Crew AI walks only where `Deck.walkable(x, z, radius)`.

## LOD policy in the game
- `ships/lod.ts`: `LOD_RANGES = [5, 18]` ship lengths (tartane ≈ 60 m / 216 m), 12 % hysteresis, and a staggered refresh (`lodUpdateDue`).
- **The player's ship is never switched** (always LOD0). `render/fleet.ts` switches the other ships (`GameView.others`) and skips ships beyond 1,100 m. Distant ships also skip wave pitch/roll sampling.
- Debug: `?perf` publishes `window.__perf = {fps, calls, triangles, lods, crew, others}`; `?lod=0|1|2` forces every other ship to that level.
- Measured with 4 patrols (tartane, sloop, brig, galleon) the triangles were dominated by the ocean mesh (~260 k) and LOD saved only ~5 k; the NPC fleet is now 12 ships (tartane … battleship), where the ladder matters more. Re-measure with `?perf&lod=0|1|2`.

## Crew GLBs (`public/models/crew/`)
See `CREW.md`. Loaded by `render/crew.ts`; appearance (variant, palette indices, hair/hat/beard) comes from `gameplay/crew.ts` through `CrewView`. Materials are cloned per sailor and tinted (`material.color`), the clips are crossfaded with `crossFadeTo` (never park an action at weight 0).
